    How it works

    Nudi (up to version 5) and Baraha's ANSI fonts, such as BRH Kannada, draw Kannada shapes on top of Latin letters. The file stores the Latin letters, so outside the font ಕನ್ನಡ reads as PÀ£ÀßqÀ. Both font families use the same layout, so 1 converter handles both.

    The fonts store glyphs in drawing order. A subscript consonant comes after the vowel sign, and some vowel signs are split into 2 or 3 pieces. The converter rebuilds each syllable in Unicode order and checks that the result is a valid Kannada syllable.

    Questions

    Is my text uploaded?

    No. The converter is compiled to WebAssembly and runs on your device. The page loads its own files and makes no other network requests. It sets no cookies and has no analytics.

    Which fonts does it convert?

    Nudi 1 to 5 fonts and Baraha ANSI fonts such as BRH Kannada. If the text already shows as Kannada letters when pasted, it is Unicode and needs no conversion. The page tells you when it sees Unicode Kannada.

    Can it convert Unicode to Nudi?

    Not yet. A Unicode to Nudi converter is coming.

    Can it convert Word files?

    Not yet. DOCX support is coming. For now, copy the text from Word and paste it here. Copying keeps the glyph codes, which is what the converter needs.

    How do I check the result?

    The report lists every glyph the converter could not place and every syllable that is not valid Kannada. Select an item to highlight it. Unknown glyphs stay in the result as they were, so nothing is lost. A measured error rate on a checked set of real documents will be published here when that test set is ready.

    What do the options do?

    Many typists entered a zero in place of the anusvara ಂ. The first option turns a zero between Kannada letters into ಂ. Leave it on unless your text has real zeros inside words. The second option is for text set in the Nudi fonts whose names end in k, which draw Kannada digits in place of 0 to 9.
